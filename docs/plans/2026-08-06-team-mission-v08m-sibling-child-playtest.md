## 測試前固定規則

本節在抽牌前固定。執行中不得因牌組強弱、關卡適配度、孩子回答或骰面修改。

### 玩家可見資訊

- 孩子只看情境、自己的動物卡、三區、後援與已取得的寶物。
- 現有揭露卡上的屬性與數字全程遮蔽。
- DM 在孩子提出方法前，不說隱藏基準、建議屬性、需求數字或適合動物。
- 每次行動先由卡片主人說方法；另一位孩子只能補一個細節，而且必須由卡片主人明確接受。

### 核心檢定流程

1. 卡片主人提出暫定動物與具體方法，尚未正式出牌。
2. DM 先對照本文件的兩條隱藏基準；真正不同的方法才使用固定轉換規則。
3. 只有缺少會改變可行性、屬性或需求數字的資訊時，DM 才問一次具體問題。
4. DM 用一句話公布必要步驟、屬性、需求數字與理由，固定 DC 4。
5. 屬性符合便沿用暫定動物；不符合時才提醒：「你可以保留這張繼續試，也可以在擲骰前免費換卡。」
6. 特殊能力直接完成必要步驟，且 `skillBonus` 包含所選屬性，才取得技能 `＋1`。
7. 孩子擲骰並結算：

```text
1d6＋屬性符合 1＋技能符合 1 ≥ DC 4
```

合理但不同的方法仍固定 DC 4。方法本身不能處理問題時不擲骰，先請孩子補充工具、合作方式或改變方法。創意、故事長度與使用技能名稱本身都不額外加分。

### 自創方法固定轉換

| 真正完成工作的主要動作 | 屬性 |
| --- | --- |
| 搬、推、拉、撐 | 力量 |
| 移動、追趕、閃避、往返 | 速度 |
| 撞、踢、咬、敲破 | 攻擊 |
| 擋住、守住、保護、承受 | 防禦 |
| 觀察、比較、規劃、使用工具解題 | 聰明 |

一句話包含兩個都可能解決問題的主動作時，只問：「真正解決問題的是哪一步？」卡片主人決定故事主要靠哪一步，DM 再轉成屬性與需求；孩子不直接指定有利屬性，DM 也不因動物最高數值改判。

| 判斷問題 | 需求數字 |
| --- | --- |
| 必須輕、慢、小心，而且太猛會破壞結果 | `1–3` |
| 必須持續收放、停走或調整，而且太弱或太猛都會出錯 | `4–6` |
| 只要求能力足夠，數值更高不會使結果變差 | `4–9` |
| 必須快速、猛烈或處理大型障礙 | `7–9` |

`4–6` 只能在過低與過高都有具體壞處時使用；不能為了配合手牌或平均分布而套用。

### 卡住與提示

不設定秒數。只有孩子出現下列任一自然情況，才算卡住：

- 明確說不知道。
- 重複情境但沒有提出動作。
- 一次必要追問後仍無法補齊方法。
- 停止參與，但尚未要求結束遊戲。

卡片屬性不符合不等於卡住。自然卡住時，一次同時念出該位置兩條「動作＋屬性＋數字」提示；孩子仍可提出第三種方法。不得為補齊資料刻意誘發提示。整局未觸發時，結論必須維持「提示未驗證」。

### 卡片所有權與共同決策

- 5 歲與 9 歲孩子各有四張起始牌；每張卡全程保有原卡主。
- 卡片主人決定出哪張卡、採用什麼方法、是否接受另一位孩子補充，以及屬性不符合時是否免費換卡。
- 另一位孩子不得替換動物、推翻原方法或代替卡主回答。
- 消耗共用後援必須兩位孩子都同意；使用哪張後援動物仍須該卡片主人同意。
- 沒有共識便不使用後援。DM 只確認雙方意見，不替孩子達成共識。
- 每次共同決策記錄 9 歲孩子是否提出建議、5 歲孩子是否自行表態，以及最後決定由誰作出。

### 一般關、後援與三區

- 第一關與第三關各用一隻主要動物。
- 第二關 A、B 各由一位孩子負責一個位置並分別檢定；兩邊都成功才完成第二關。
- 單動物任務失敗，或第二關只有一邊失敗時，可消耗一次共用後援，換另一隻動物重做失敗位置。
- 第二關兩邊都失敗時，一次後援無法完成整關，因此不消耗後援。
- 本關剛失敗的主要動物不能立即救自己。
- 任務成功或後援補救成功時，隨機取得一件尚未取得的寶物；失敗不抽，但故事繼續。
- 完成自己工作：進休息區。
- 第一次出場失敗：進再挑戰區，之後只可再當一次後援。
- 第二次出場後：不論結果都進休息區。
- 全隊共有兩次後援，前三關與 Boss 共用，不補充。

### Boss 寶物固定順序

Boss A、B 各做一次 DC 4 檢定，兩邊都成功才通關。固定順序不得更改：

1. 萬用背包：第一次擲骰前，由兩位孩子共同指定一個位置取得 Advantage，擲 `2d6` 取高。
2. A、B 完成第一次擲骰。
3. 探險手電筒：只在兩個第一次結果都出來後，將其中一個總分剛好為 3 的結果改為 4；不能作用於魔鏡或後援。
4. 變化魔鏡：選一個失敗位置，以普通 `1d6` 重做。使用後把魔鏡壓在該位置旁，不論重做結果，該位置都不能再接受後援。
5. 全隊後援：寶物結算後若只剩一邊失敗，且該位置未使用魔鏡，才可換另一隻動物重做。

魔鏡與後援都不繼承背包 Advantage。兩邊都失敗時，必須先由魔鏡救回一邊，才能後援另一邊；魔鏡仍失敗便不消耗後援。
