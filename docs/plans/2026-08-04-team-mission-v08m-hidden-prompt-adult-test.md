# 團隊任務 v0.8-M 隱藏基準／提示制成人測試

> 日期：2026-08-04
> 狀態：完成；自由方法與裁定初步通過，使用者選擇不做刻意提示短測，備選提示維持未驗證
> 性質：成人代理的流程與裁定壓力測試；不代表 5 歲或 9 歲真人驗證

## 前一測試為何停止

原定 v0.8-H／v0.8-M 公開資訊 A／B 在第一題即停止。v0.8-H 把速度與聰明套用同一組 `4、5、6`，玩家在選卡前便質疑「為什麼聰明 7 反而不適合找路」。這不是文案問題，而是不同方法不應共用同一需求。

其後原本公開的兩個方法也改為備選提示：先讓孩子從手中動物想方法，只有卡住時才揭露。前一測試與 1H 原話保留於 [`2026-08-04-team-mission-v08m-adult-ab-test.md`](2026-08-04-team-mission-v08m-adult-ab-test.md)。

## 只回答一個問題

> 「孩子先自由想方法，DM 用預寫基準裁定；卡住才揭露兩個提示」能否同時保留創意、讓五屬性有明確用途，並把 DM 的臨場裁量控制在可接受範圍？

本輪不驗證 Boss、寶物、後援、完整劇情節奏或實際兒童學習。孩子不參與未定案版本的反覆測試；紙筆規格穩定後才學一次接近定案的版本。

## 核心流程

1. DM 只說情境與目標，不公開屬性、數字或預寫方法。
2. 玩家可看手牌找靈感，提出暫定動物與具體方法；此時尚未正式出牌。
3. DM 先對照兩條預寫裁定基準：
   - 方法相近：沿用該基準的必要步驟、屬性與需求數字。
   - 方法明顯不同：依固定轉換規則裁定。
4. DM 用一句話公布必要步驟、屬性、需求數字與理由。
5. 屬性符合時直接沿用暫定動物；屬性不符合時，DM 才提醒「仍可嘗試，或免費換動物」。玩家也可在擲骰前主動改方法或換卡。
6. 屬性數字符合需求便取得 `＋1`。
7. 技能直接完成必要步驟，且技能加成包含所選屬性，才取得 `＋1`。
8. 擲骰並結算：

```text
1d6＋屬性符合 1＋技能符合 1 ≥ DC 4
```

本輪每題固定骰面 `3`，只測理解與選擇，不比較運氣或勝率。

## DM 的固定轉換規則

### 先選主要屬性

只選一個真正完成工作的主要動作：

| 主要動作 | 屬性 |
| --- | --- |
| 搬、推、拉、撐 | 力量 |
| 移動、追趕、閃避、往返 | 速度 |
| 撞、踢、咬、敲破 | 攻擊 |
| 擋住、守住、保護、承受 | 防禦 |
| 觀察、比較、規劃、使用工具解題 | 聰明 |

若一句話包含多個動作，DM 只問一次：「真正解決問題的是哪一步？」回答後再選屬性，不因動物最高數值改判。

簡單答案只要已說出「做法類型＋處理目標」，且缺少的畫面細節不會改變可行性、屬性或需求數字，便直接裁定。不能為了故事完整度要求孩子補充身體部位、姿勢或連接詞。

### 再選需求數字

| 判斷問題 | 需求數字 |
| --- | --- |
| 工作必須輕、慢、小心，而且太猛會破壞結果嗎？ | `1、2、3` |
| 必須持續收放、停走或調整，而且太弱或太猛都會出錯嗎？ | `4、5、6` |
| 只要求具備足夠能力，數值更高不會使結果變差嗎？ | `4、5、6、7、8、9` |
| 必須快速、猛烈或處理大型障礙嗎？ | `7、8、9` |

`4、5、6` 只能在「過低與過高都確實有壞處」時使用，不能只因設計需要中間數字便套用。聰明通常使用 `4–9`；除非該方法能具體說明持續調整過度也會造成錯誤，否則不用 `4–6`。

### 防止迎合手牌

- 先依孩子描述的動作裁定，再看是否保留動物。
- 不得因暫定動物剛好有某個高分，改選有利屬性或需求。
- 方法含糊時先追問動作，不以卡片技能替孩子補寫。
- 玩家知道裁定後仍保有免費換動物的權利，因此不需用偏袒裁定來保護原選擇；但屬性已符合時不增加固定確認步驟。

## 兩條預寫基準如何兼作提示

平常兩條基準只在 DM 端。DM 自行判斷玩家是否卡住，不設固定秒數。可考慮提供提示的情況包括：

- 明確說不知道。
- 重複情境但沒有可執行動作。
- 經一次「真正解決問題的是哪一步？」追問仍無法補完整。
- 開始煩躁、分心或停止參與。

不能只因暫定動物不符合需求就提供提示。

決定提示時，同時揭露兩條，直接顯示「動作＋屬性＋數字」。玩家可選其中一條，也可繼續提出第三種方法。

## 四個測試情境

### 第一題：雨水蓋住的石頭路

玩家只聽到：

> 雨水蓋住一部分石頭路，有些石頭會滑，有些踩下去會搖。隊伍要找出一條能慢慢通過的安全路線。

DM 預寫基準：

1. `走一段 → 停穩 → 再走｜速度 4、5、6`
2. `看水流 → 比較高地｜聰明 4、5、6、7、8、9`

### 第二題：送出玻璃藥瓶

玩家只聽到：

> 幾瓶救援藥品要越過滿是樹根的小路，玻璃瓶不能摔破，山腳的水又正在上升。

DM 預寫基準：

1. `托穩一瓶 → 輕輕放入箱子｜力量 1、2、3`
2. `一次帶一瓶 → 快速來回｜速度 7、8、9`

### 第三題：崩塌的漂流木堆

玩家只聽到：

> 漂流木堆堵住唯一的排水口，積水還在上升。隊伍要盡快拆出一個排水破口。

DM 預寫基準：

1. `對準粗木 → 猛力撞開｜攻擊 7、8、9`
2. `找出鬆木 → 敲開接點｜聰明 4、5、6、7、8、9`

### 第四題：搖晃的藤橋

玩家只聽到：

> 藤橋被風吹得不停搖晃，幾條綁住橋面的細藤也從固定點鬆開了。隊伍要讓藤橋重新穩住，才能安全通過。

DM 預寫基準：

1. `拉住主藤 → 晃動時調整｜防禦 4、5、6`
2. `靠近鬆藤 → 輕輕拉回固定｜力量 1、2、3`

## 每題記錄

| 欄位 | 記錄方式 |
| --- | --- |
| 第一次有效回答 | 暫定動物與玩家原話 |
| 追問 | 次數及原文 |
| 提示 | 未使用／使用；DM 判斷觸發原因 |
| 裁定來源 | 預寫基準 1／預寫基準 2／自創方法 |
| DM 公布 | 必要步驟、屬性、需求數字與一句理由 |
| 正式選卡 | 屬性符合而直接沿用／不符後仍保留／換成哪隻動物 |
| 加值 | 屬性分、技能分；技能完成哪個必要步驟 |
| 結果 | 固定骰面 `3`、總分與成功／失敗 |
| 裁定負擔 | 直接對應／需一次追問／仍有歧義 |
| 選擇品質 | 至少兩個合理取捨／唯一明顯答案／資訊不足 |

孩子正式遊玩時不必口頭預測兩種加值；可用兩枚 `＋1` 標記表示。成人測試會記錄玩家是否能理解，但不把正式規則用語當成玩家台詞要求。

## 通過條件

進入完整成人紙筆局前，新流程至少要同時滿足：

1. 玩家可先從動物提出方法，不需先看數字答案。
2. DM 能用預寫基準或固定規則說出一致、可理解的裁定，不迎合手牌。
3. 公布裁定後，玩家知道原動物為何適合或不適合；免費換卡不被感受為處罰。
4. 屬性與技能都實際影響選擇，技能 `＋1` 不需 DM 補寫故事。
5. 提示出現時提供兩個實質不同方向，不是兩種說法包裝同一張最佳卡。
6. 流程不退化為唯一答案配對，也不回到完全依賴動物知識與語言表達。

若大部分方法都能直接對應預寫基準，表示 DM 負擔可控。若自創方法頻繁需要爭論屬性或需求，先修裁定規則，不直接進完整局。若提示總是導向唯一最佳卡，需調整方法需求或測試牌組。

## 本輪之後

- 通過：用六個正式位置跑一局成人紙筆《暴雨森林救援隊》，再檢查十二條預寫基準、Boss、寶物與後援。
- 問題局部：只修改裁定文字、提示或需求分配，再做短回歸。
- 仍高度依賴 DM 臨場說服：保留 v0.7 為基準，重新評估是否繼續 v0.8 路線。
- 完整紙筆規格穩定前，不修改 `game/dm/`、揭露卡、寶物卡或 PDF。

## 執行紀錄

### 第一題：雨水蓋住的石頭路

- 第一次有效回答：`海獺擅長在有水的環境移動，牠小心翼翼檢查每塊石頭，找出一條安全通過路線`
- 暫定動物：海獺。
- 追問：0。
- 提示：未使用；方法已包含可執行的「逐塊檢查」。
- 裁定來源：接近預寫基準 2 的觀察／比較方法。
- DM 公布：必要步驟是逐塊檢查並比較石頭是否安全；主要靠聰明，需求為 `4、5、6、7、8、9`。理由是只需要足夠的觀察判斷能力，更高的聰明不會造成壞處。
- 正式選卡：海獺聰明 7 已符合，依修正流程直接沿用，不增加固定確認步驟。
- 加值：海獺聰明 7 符合，屬性 `＋1`；「石擊破殼」沒有直接完成檢查與比較，技能 `＋0`。
- 裁定負擔：直接對應；雖然回答也提到水中移動，但「檢查每塊石頭」已清楚指出真正解決問題的步驟，不需追問速度或聰明。
- 選擇品質：不是唯一答案；非洲獅聰明 5 也符合，其他動物仍可能提出不同移動方法。
- 結果：固定骰面 `3`，總分 `3＋1＝4`，成功。
- 流程發現：免費換卡是裁定公布後的玩家權利，不是每回合固定詢問。只有屬性 `＋0` 時，DM 才主動提醒「仍可嘗試，或換一隻」；技能 `＋0` 不單獨觸發換卡詢問。

### 第二題：送出玻璃藥瓶

- 第一次有效回答：`蜂鳥用嘴巴叼著藥瓶飛過去`
- 暫定動物：蜂鳥。
- 提示：未使用；方法已包含可執行的「叼著飛過樹根」，不屬於卡住。
- 待追問：情境有好幾瓶，回答目前只處理一瓶。DM 不暗補「快速來回」，只追問如何把全部送完。
- 追問原文：`有好幾瓶藥。蜂鳥準備怎麼把全部藥瓶都送過去？`
- 玩家補充：`快速來來回回`
- 裁定來源：直接對應預寫基準 2。
- DM 公布：必要步驟是一次叼一瓶並快速往返；主要靠速度，需求為 `7、8、9`。理由是必須在水上升前多次完成運送。
- 正式選卡：蜂鳥速度 8 已符合，直接沿用。
- 加值：速度 8 符合，屬性 `＋1`；「懸停疾閃」直接完成快速往返飛行且對應速度，技能 `＋1`。
- 結果：固定骰面 `3`，總分 `3＋1＋1＝5`，成功。
- 裁定負擔：需一次必要追問；追問只補齊複數目標，沒有提供屬性、數字或提示方法。
- 選擇品質：快速往返路線明顯適合蜂鳥，但這是玩家先從動物提出的方法；同一情境仍有輕拿慢放的另一條預寫路線，不是整題只有蜂鳥一個答案。

### 第三題：崩塌的漂流木堆

- 第一次有效回答：`海獺用石擊破殼的技巧，找出漂流木的破綻，用石頭敲出破口`
- 暫定動物：海獺。
- 追問：0。
- 提示：未使用；方法已包含找破綻與用石頭敲開兩個具體步驟。
- 裁定來源：直接對應預寫基準 2。
- DM 公布：必要步驟是找出鬆動接點，再用石頭敲開；主要靠聰明，需求為 `4、5、6、7、8、9`。理由是靠觀察與工具使用解題，聰明更高不會造成壞處。
- 正式選卡：海獺聰明 7 已符合，直接沿用。
- 加值：聰明 7 符合，屬性 `＋1`；「石擊破殼」直接完成找弱點並用石頭敲開的必要步驟，且對應聰明，技能 `＋1`。
- 結果：固定骰面 `3`，總分 `3＋1＋1＝5`，成功。
- 裁定負擔：直接對應；「找出破綻」已清楚表明主要是聰明解題，不需在攻擊與聰明之間追問。
- 選擇品質：海獺在此路線可取得 `＋2`，但非洲獅聰明 5 也可執行觀察路線；另一條正面撞開路線則適合非洲獅或使用飛踢的紅袋鼠，不是全題唯一答案。

### 第四題：搖晃的藤橋

- 第一次有效回答：`非洲獅用蠻力把橋穩住（模擬測試 5y 只能想出比較簡單的答案）`
- 暫定動物：非洲獅。
- 追問：0。
- 提示：未使用；「用蠻力」已說明方法類型，「把橋穩住」已說明目標，缺少身體部位不影響裁定。
- 裁定來源：自創方法。
- DM 公布：必要步驟是用強大力量直接穩住橋；主要靠力量，需求為 `7、8、9`。理由是玩家明確選擇蠻力處理整座橋，屬於大型、強力工作。
- 正式選卡：非洲獅力量 7 已符合，直接沿用。
- 加值：力量 7 符合，屬性 `＋1`；「雄獅怒吼」沒有直接完成穩住橋的必要步驟，技能 `＋0`。
- 結果：固定骰面 `3`，總分 `3＋1＝4`，成功。
- 裁定負擔：固定轉換規則可直接處理，不需逼玩家把簡單答案擴寫成完整故事。
- 選擇品質：力量 `7–9` 在測試手牌中只有非洲獅符合，但這條路線由玩家先從非洲獅自由提出；預寫的持續調整與輕拉固定仍提供其他動物路線，不是情境只有唯一答案。

## 四題初步結果

- 四題都有可執行的自由方法，備選提示使用 `0` 次。
- 兩題直接對應預寫基準，一題經一次必要追問後對應預寫基準，一題使用固定轉換規則處理自創方法。
- 唯一追問只補齊「如何運完複數藥瓶」，沒有提示屬性、數字或最佳動物。
- 四題裁定都能在公布後直接沿用暫定動物，免費換卡使用 `0` 次。
- 屬性 `＋1` 出現四次；技能 `＋1` 出現兩次、`＋0` 出現兩次，沒有因提到技能名稱便自動加分。
- 沒有再次出現「高聰明反而不適合觀察」的矛盾；兩個觀察／工具方法都使用 `4–9`。
- 第四題刻意使用 5 歲式簡單句，證明「做法類型＋目標」已足夠時可直接裁定；這仍是成人代理的邊界檢查，不是實際兒童證據。
- 尚未驗證：DM 何時判斷卡住、同時揭露兩個提示後是否好懂，以及提示是否會退化為唯一答案配對。

## 本輪結論

### 已取得的證據

- 「先從動物自由想方法，再由 DM 對照隱藏基準」四題都可完成，沒有回到先看數字配答案。
- DM 可用兩條預寫基準與固定轉換規則處理三種情況：直接對應、一次必要追問、自創簡單方法。
- 屬性需求能說明為何適合；聰明方法改用 `4–9` 後，沒有再出現高聰明反而被排除的矛盾。
- 技能是否加分可由必要步驟區分，四題中兩次 `＋1`、兩次 `＋0`。
- 屬性符合時直接結算，不固定詢問是否換卡；這比原測試流程自然。

### 不能宣稱的結論

- 四題都是成人代理，不能證明 5 歲或 9 歲孩子能自行提出相同方法。
- 第四題只是成人刻意使用簡單句，僅證明規則能接受簡單回答，不是兒童理解證據。
